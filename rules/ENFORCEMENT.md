# Enforcement ledger

Every rule, and whether anything actually stops it being broken. Generated by
reading the Enforcement line off each rule; if this disagrees with a rule file,
the rule file wins and this needs regenerating.

`check-rules` fails the build if any rule in this folder has no Enforcement
line, so a new rule cannot be added without declaring its status.

Audited 2026-08-19. Totals: Audit 1, Guard 23, Honour 43, None 2, Partial 15, Retired 1, 85 rules.

| Status | Meaning |
|---|---|
| **Guard** | A shared module or build check makes it impossible. |
| **Partial** | A guard exists but does not cover the whole rule. Gap named in the row. |
| **Audit** | Nothing stops it; a job reports the break afterwards. |
| **Honour** | Nothing stops it and nothing reports it. |
| **None** | Known hole, no owner yet. |
